# Generador de Artículos por Revista

Sistema web (un solo `index.html`, sin compilación) para preparar artículos científicos breves (4–8 páginas publicadas) adaptados a 36 revistas de Perú y Latinoamérica: extensión, estructura, estilo de citas, enfoque disciplinar, prompts por fase, verificación de fuentes (OpenAlex, Crossref, DataCite) y auditoría previa al envío.

- `index.html`: la aplicación.
- `catalogo-revistas.csv`: catálogo de revistas con lo verificado y lo que falta verificar.
- `LEEME.md`: guía rápida y decisiones tomadas.
- `informe-arbitro.md`: resumen de las 17 rondas de auditoría adversarial.
- `render.yaml`: despliegue como sitio estático en Render.
